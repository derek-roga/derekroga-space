Printer Help

Print a test page, find the fault, fix it. These guides start from what you see on the page, not from a settings menu.

How this works

A printer problem is something you see: a blank page, a faded photo, a colour that is missing, a line that should not be there. So these guides start from the symptom. Find what your print looks like below, open the guide, and it will walk you through the causes in the order to check them, the fix for each one, and the test page that proves the fix worked.

Every guide points at the same tool: Derek's free printer test page utility. Five sheets, each matched to a symptom, as exact-size A4 and US Letter PDFs. No sign-up, no cost.

Diagnosis guides

Symptom-first guides: the cause ladder, the fix per cause, and the sheet that proves it.

  • Why is my printer printing blank pages?

    Quick checks first, then the cause ladder: empty or clogged cartridges, dried heads, driver faults, and the blank-page setting.

  • Faded prints

    Light overall, patchy, or one colour faded: three different faults, three different fixes. Includes the draft-mode check, the commonest "fault" that is not a fault.

  • Printer printing wrong colours

    Colour cast, missing colour, or muddy colours. Diagnose by isolating channels with the CMYK sheet.

  • Streaks and lines on prints

    Read the pattern first: horizontal or vertical, regular or random, colour or black only. The pattern is the diagnosis.
