TestPrintPage

TestPrintPage is a free printer test page utility built by Derek Roga at Essence Technologies in Vilnius, Lithuania. It launched in November 2026. Anyone can print a test page to check their printer, free, with no account needed.

The five sheets

  • Quick: one page that checks everything at a glance
  • Colour: checks colour output, blocks and gradients
  • Black and White: checks mono printing, grey steps and text sharpness
  • CMYK: isolates each ink channel so you can see which one is failing
  • Alignment: checks print-head alignment for blurry or offset prints

Every sheet is an exact-size A4 or US Letter PDF. Browse the printer guides →
